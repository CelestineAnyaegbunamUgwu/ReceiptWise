
# ReceiptWise Sample Data

This directory is reserved for sample receipt images and supporting test data.

## Data Guidelines

- Use publicly licensed datasets or synthetic receipts.
- Do not upload private receipts containing personal or financial information.
- Keep large datasets outside the Git repository unless explicitly required.
- Document the source and license of any dataset used.

## Planned Dataset

CORD v2 will be used for receipt OCR and structured information-extraction experiments.

Official dataset:
https://huggingface.co/datasets/naver-clova-ix/cord-v2
